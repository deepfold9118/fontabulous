## [0.1.0] - 2026-11-22

### Added
- The first release: a font manager for Windows with a light and a dark
  theme, Lucide icons and the ArtCraft look.
- Browse fonts in folders, the installed Windows fonts and a Worklist of
  loose font files (save and reopen worklists). List, tiles and details
  views, with sorting.
- Preview panes: text sample, characters table, waterfall, and the font's
  properties.
- Install, activate temporarily (until sign-out, without installing), and
  uninstall or deactivate fonts.
- Groups (also created from a folder structure), a library, ratings and
  tags with one-click Usage and Mood tags; export and import tags.
- Filters tab: classification, mood and usage tags, recommendations,
  weight, width, x-height, contrast, language support and foundry, with
  counts. Values come from an attached font-library catalog
  (`_Catalog\catalog.json`), or are measured from the fonts.
- Find Fonts, Search for Duplicates, Compare, Show Kerning Pairs, Detect
  Font Problems, export to an HTML page, and copy font files to a folder.
- An installer for the current user (no administrator rights needed) with
  Start menu and desktop shortcuts and an Installed apps entry.
